# RIGZER ABOUT WEBSITE

## WHAT THIS IS

A static **About website for Rigzer**, built with HTML, CSS, and JavaScript. It introduces Rigzer, showcases its features, and provides access to the Game Shelf and Rigzer Radio.


## WEBSITE FILES

- `index.html` — The main About page for Rigzer.
- `playshelf.html` — The Game Shelf, displayed within the website.
- `radio.html` — Rigzer Radio, displayed within the website.
- `rd/` — Images and short looping videos used by Rigzer Radio.
- `*.webp` / `*.mp4` — Images and the hero video used by the main page.
